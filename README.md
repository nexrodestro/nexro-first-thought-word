## The word

**squelch** — the first word that came to mind. A wet footstep in mud:
a sound you can hear, an image you can feel, a word that is fun to say.
Surprising (not the safe rare-word pick), vivid (mud underfoot),
with a spark of wit in its onomatopoeia.

## How it works

`main.ts` writes exactly that one word to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` or `/output`), UTF-8, 7 characters, no trailing
newline — inside the gate's 1–24 character window.

## Run

```sh
node main.ts
cat /output/entry.txt  # squelch
```
